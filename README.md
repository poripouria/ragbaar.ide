# RagbaarNet — Typing Channel

> **Note:** This repository is a simple use-case preview of the main project: **[RagbaarNet](https://github.com/poripouria/RagbaarNet)**.

## Introduction
RagbaarNet — Typing Channel is a functional UI demonstration that showcases the integration of human-computer interaction with real-time generative music. It transforms standard user inputs into a live orchestral performance using deep learning models executed locally in the browser.

## Key Features
*   **Real-time Interaction Sonification:** Converts keystrokes, mouse movements, and scrolling events into immediate musical responses.
*   **Edge Computing Inference:** Utilizes a Long Short-Term Memory (LSTM) model running entirely client-side for low-latency performance.
*   **Developer-Centric UI:** Features a code-editor-inspired interface with dynamic syntax highlighting.
*   **Live Feedback:** Provides visual and auditory status updates, including note counts and connection health.

## Core Technologies
*   **Tone.js:** For high-fidelity browser-based audio synthesis and orchestral soundscapes.
*   **ONNX Runtime Web:** For efficient, hardware-accelerated model inference.
*   **Prism.js:** For modular and performant code syntax highlighting.
*   **Vanilla JS & CSS3:** For a lightweight and responsive web experience.
